# 图像制作记录

默认内置图像生成方式制作8幅外观教学图，项目内保留PNG；所有图均已嵌入正文。各幅均采用纵向构图、奶油色背景、自然光、食物编辑摄影风格，无文字、不固定六格。以下为提示要点，非逐字原始提示词。

| 文件 | 画面对象与关键要求 | 正文用途 |
| --- | --- | --- |
| rice-comparison.png | 致密米糕、多孔米发糕、煎萝卜糕；清楚切面 | 第05章比较不同米制组织 |
| pastry-comparison.png | 中式酥点、蜂窝状可颂、空腔泡芙；不同膨起结构 | 第12章跨工艺比较 |
| world-comparison.png | 草莓大福、samosa、baklava、empanada；代表切面 | 第16章世界结构比较，联系第15章 |
| cold-comparison.png | 焦糖布丁、奶冻、巧克力慕斯、冰淇淋与sorbet | 第14章辨认外观，正文另讲机制 |
| steamed-comparison.png | 虾饺、发面肉包、广式烧卖、煎锅贴；皮馅差异 | 第07章咸点对照 |
| cakes-comparison.png | 磅蛋糕、戚风切件、烤芝士蛋糕；不同组织 | 第11章蛋糕比较 |
| tarts-comparison.png | 曲奇皮蛋挞、葡式酥皮蛋挞、双皮苹果派、shortbread | 第13章酥壳与小饼 |
| festival-comparison.png | 叶包粽子、莲蓉蛋黄月饼、黑芝麻汤圆 | 第09章当代节令代表外观 |
