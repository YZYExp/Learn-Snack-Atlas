# 中式点心代表索引

本表方便按品名回查，收录书内涉及的代表点心，不是全部中式点心的清单。“主导原料与工艺”描述常见版本；同名点心在各地可能有不同配方，辨认时应结合包装、店家说明和实际断面。

| 品名或常见款式 | 主导原料与工艺 | 辨认线索及地方差异 | 回查 |
| --- | --- | --- | --- |
| 年糕 | 米粉团或蒸米经加工形成致密糕体 | 切面通常连续紧实；各地糯米、粳米比例及甜咸不同 | [米与杂粮](../chapters/05-rice.md) |
| 松糕 | 湿润米粉粒入模蒸结 | 留有细孔，易掰松；名称与配方因地区而异 | [米与杂粮](../chapters/05-rice.md) |
| 定胜糕 | 常见为米粉入模蒸制 | 多见小型模压糕；不以本表确定统一形状与配方 | [米与杂粮](../chapters/05-rice.md) |
| 青团 | 植物与米粉团结合，常包馅蒸熟 | 青绿色外皮；用草、配粉及甜咸馅各有差别 | [米与杂粮](../chapters/05-rice.md) |

| 打糕 | 熟米捶打形成连续组织 | 米粒经破碎黏合；用米和表层配料有地方差异 | [米与杂粮](../chapters/05-rice.md) |
| 糍粑 | 常由熟糯米捣打成形 | 黏糯紧实；可另行烤、煎或配糖，名称不限定一种吃法 | [米与杂粮](../chapters/05-rice.md) |
| 广式糖浆皮月饼 | 糖浆皮包馅、压模后烤制 | 皮有压纹，常较柔润；馅有甜咸多种 | [中式酥点](../chapters/06-chinese-pastry.md) |

| 冰皮月饼 | 熟化的软韧粉皮包馅成形 | 不经传统烤皮路线；通常需依具体产品要求冷藏 | [中式酥点](../chapters/06-chinese-pastry.md) |
| 烧饼 | 小麦面团经烙烤等加热 | 可分层、可发面，甜咸均有；不能只凭芝麻判断内部工艺 | [中式酥点](../chapters/06-chinese-pastry.md) |
| 桃酥 | 油脂、糖、面粉等形成松酥烤点 | 常为颗粒状易碎结构，不要求整齐层状断面 | [中式酥点](../chapters/06-chinese-pastry.md) |
| 麻花 | 条状面坯扭结后炸制 | 扭结形态与脆口；夹酥、粗细及软硬版本不同 | [中式酥点](../chapters/06-chinese-pastry.md) |
| 港式酥皮蛋挞 | 分层挞皮装蛋浆烤制 | 挞壳薄层可剥落；与曲奇皮款区分 | [中式酥点](../chapters/06-chinese-pastry.md) |
| 港式曲奇皮蛋挞 | 短酥类挞壳装蛋浆烤制 | 外壳较连续，咬开为松碎颗粒状 | [中式酥点](../chapters/06-chinese-pastry.md) |
| 澳门葡挞 | 分层酥皮配蛋奶浆烤制 | 常见焦斑蛋面与层状挞皮；各店配方不同 | [中式酥点](../chapters/06-chinese-pastry.md) |
| 发面肉包 | 发酵小麦面皮包肉馅后蒸制 | 外皮有气孔，封口完整；馅料切配和调味各异 | [包饺与咸点](../chapters/07-steamed-savory.md) |
| 叉烧包 | 叉烧馅配发酵面皮，常见蒸或烤款 | 松软包体与叉烧馅；不能只凭是否开花辨名 | [包饺与咸点](../chapters/07-steamed-savory.md) |
| 水饺 | 非发酵面皮包馅后水煮 | 薄韧完整的封口皮；各地形态和馅料多变 | [包饺与咸点](../chapters/07-steamed-savory.md) |
| 蒸饺 | 面皮包馅后蒸熟 | 皮不持续浸水；普通面团、烫面及其他做法有别 | [包饺与咸点](../chapters/07-steamed-savory.md) |
| 锅贴 | 包馅面坯锅内煎制，常结合加水焖蒸 | 底面干脆，上部较柔软；各地开口或封口有别 | [包饺与咸点](../chapters/07-steamed-savory.md) |

| 广式烧卖 | 薄皮托住肉虾等馅料后蒸制 | 开放顶部露馅；具体肉虾配合各店不同 | [包饺与咸点](../chapters/07-steamed-savory.md) |
| 糯米烧卖 | 薄皮包裹糯米类馅料后蒸制 | 开口或收口处可见糯米主体；馅的配料各地不同 | [包饺与咸点](../chapters/07-steamed-savory.md) |
| 翡翠烧卖 | 薄皮与蔬菜馅等组合蒸制 | 常见皮薄透绿的菜馅路线；以扬州茶点为书内案例 | [包饺与咸点](../chapters/07-steamed-savory.md) |
| 三丁包 | 发面皮包切丁组合馅后蒸制 | 重点是馅料颗粒与包皮的配合；以富春茶点为案例 | [包饺与咸点](../chapters/07-steamed-savory.md) |
| 小笼包 | 薄皮包馅蒸制，部分做法使用肉皮冻 | 皮内保留汤汁；大小、皮厚及汤汁量各有风格 | [包饺与咸点](../chapters/07-steamed-savory.md) |

## 使用这张索引

先看名称，再核对主导原料和断面；发现地方版本不同，不必强行更正为表中的一种。表内“常见”不是对传统的等级评判。具体来源与解释见对应章节，节令和礼俗含义应连同其地区范围一起阅读。
