# 附录　工艺词汇与阅读路线

## 先把容易混淆的词分开

| 词语 | 本书采用的含义 | 不应直接推断什么 |
| --- | --- | --- |
| 糊化 | 淀粉在适当水分与加热条件下发生结构变化 | 所有粉料都在相同温度完成 |
| 陈化 | 食品随存放出现的组织变化，可涉及淀粉重新排列与水分迁移 | 只是水分蒸发 |
| 面筋 | 小麦相关蛋白质水化与操作后形成的网络 | 越强越适合所有糕点 |
| 发酵 | 微生物活动参与改变原料、风味和气体状态 | 凡是蓬松都经过发酵 |
| 打发 | 搅打引入空气并使其分散在体系中 | 越久越好、越硬越好 |
| 乳化 | 油水等不易混溶相在体系中适当分散 | 只要搅拌就必然稳定 |
| 水油皮 | 中式酥点中可包住油酥并延展的外层面团 | 一碗油和水 |
| 油酥 | 面粉与油脂等组成的酥性部分 | 必须使用某一种动物油 |
| 起酥 | 有意建立并维护面层与油脂层的技术 | 所有松碎点心都是千层 |
| 短酥 | 较易咬断、松散的组织目标 | 成品长度较短 |
| 盲烤 | 在加馅前先烤空壳，可分部分或完全预烤 | 所有派都必须进行 |
| 蛋奶凝固 | 蛋参与受热后的增稠或凝固 | 所有叫布丁的食品都如此 |
| 胶凝 | 体系形成能在一定条件下保持形状的网络 | 一定含动物明胶 |
| 慕斯 | 强调泡沫组织的一类甜点 | 一定含生蛋或一定含明胶 |
| 软糯 | 日常感官描述，需要拆成黏、弹、韧等观察 | 一定含糯米 |
| 富集面团 | 加入糖、油脂、蛋乳等丰富配料的面团 | 自动代表营养更均衡 |
| 复脆 | 用适当方式改善部分成品的脆感 | 可以挽救保存不当的易腐食品 |
| 植物基 | 配方以植物来源原料为取向，具体以标示为准 | 必然低糖、低脂、无过敏原 |

这些是便于阅读的解释，不替代完整食品科学定义。相关机制与资料分别见第02—04、10—14、17章。

## 可以怎样读这本书

从熟悉食物进入：先读第05—09章，再回头理解第02—04章。

以烘焙为兴趣：先读第02—04章，再按第10—14章进入各工艺家族，最后用第17章理解配方替换。

以旅行与饮食文化为兴趣：先读第01、08、09、15、16章，再用索引寻找想认识的品种。

以日常购买为兴趣：先读第04与18章，做一次同类比较，再返回具体品种章节。
