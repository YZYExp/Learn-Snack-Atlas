# 附录　工艺词汇、原文与阅读路线

本书以中文解释为主。外文用来查阅配方、菜单和原始资料：标作法语、意大利语、日语等的是对应语言名称；“英语描述”只是便于检索的说法，不表示该食品起源于英语地区。中式地方名若没有一一对应的外文，就保留中文及具体解释。

正文上标数字可进入本章注释，注释中的“返回正文”链接回到原处。网页将注释放在章末；EPUB提供相同的往返链接，支持相应功能的阅读器也可显示弹出注释。

## 先把容易混淆的词分开

| 词语 | 常用原文或对应表达 | 本书采用的含义 | 不应直接推断什么 |
|---|---|---|---|
| 糊化 | starch gelatinization / gelatinisation | 淀粉在适当水分与加热下发生结构变化 | 所有粉料都在同一温度完成 |
| 陈化 | staling | 存放中的组织变化，可涉及回生与水分迁移 | 仅是水分蒸发，或与回生完全同义 |
| 面筋／麸质 | gluten | 小麦相关蛋白质水化与操作后形成的网络，具体语境见第02章 | 越强越适合所有糕点 |
| 发酵 | fermentation | 微生物活动改变原料、风味和气体状态 | 凡是蓬松都经过发酵 |
| 打发 | whipping（常用英语表达） | 搅打引入空气并使其分散 | 与糖油打发法creaming在所有配方里相同 |
| 乳化 | emulsification | 使油水等不易混溶的相适当分散 | 只要搅拌就必然稳定 |
| 水油皮 | 中式酥点术语 | 能包住油酥并延展的外层面团 | 一碗油和水 |
| 油酥 | 中式酥点术语 | 面粉与油脂等组成的酥性部分 | 必须使用某一种动物油 |
| 包油起酥分层 | lamination | 建立并维护面层与油脂层 | 所有“酥”或shortening都属于这一过程 |
| 短酥 | short；shortcrust pastry为相关面团名 | 较易咬断、松散的组织目标，依面团语境解释 | 成品长度较短，或等同千层酥 |
| 盲烤 | blind baking | 加馅前先烤空壳，可部分或完全预烤 | 所有派都必须如此 |
| 蛋奶体系 | custard | 蛋参与增稠或凝固的相关体系 | 所有叫pudding的食品都属于此类 |
| 胶凝 | gelation | 形成凝胶或网络的过程 | 一定含动物明胶，或与淀粉糊化同义 |
| 慕斯 | mousse（法语） | 强调泡沫组织的一类甜点 | 一定含生蛋或明胶 |
| 软糯 | 中文日常感官描述 | 需拆成黏、弹、韧等观察 | 一定含糯米 |
| 富集面团 | enriched dough | 加入糖、油脂、蛋乳等较丰富配料的面团 | 自动代表营养更均衡 |
| 复脆 | 中文操作描述 | 用适当方式改善部分成品的脆感 | 能挽救保存不当的易腐食品 |
| 植物基 | plant-based | 配方以植物来源原料为取向，须看实际标示 | 必然低糖、低脂、无过敏原 |

这些解释用于阅读，不替代完整食品科学定义。相关机制见第02—04、10—14、17章。[胶凝术语参照：IUPAC Gold Book](https://goldbook.iupac.org/terms/view/GT07621)；[打发与混合方法参照：Columbus State Community College，The Bakeshop](https://library.oercommons.org/oh-cr/hosp_2218_the_bakeshop/01_01_01.html)。

## 可以怎样读这本书

从熟悉食物进入：米糕、酥点与茶点可先读第05—09章；饺子、馄饨、汤圆和早餐可从第19—23章进入，再回头理解第02—04章。

以烘焙为兴趣：先读第02—04章，再按第10—14章进入各工艺家族，最后用第17章理解配方替换。

以旅行与饮食文化为兴趣：先读第01、08、09、15、16与24章，再用索引寻找想认识的品种。

以日常购买为兴趣：先读第04与18章，做一次同类比较，再返回具体品种章节。
